# qtcloud-connect 使用指南

## 这是什么

qtcloud-connect 是一个**人机沟通共识工具**。它能帮你和 AI 聊完天后，自动把聊出来的结论记下来，整理成"共识卡片"，不会忘记、不会搞混。

和普通聊天工具的区别：

| | 普通聊天 | qtcloud-connect |
|--|---------|----------------|
| 聊完 | 信息散落在对话里，翻半天才能找到 | AI 自动提炼结论，生成共识卡片 |
| 确认 | 口头说"好的就这样" | 共识卡有明确的"待确认→已确认→已废弃"状态 |
| 追溯 | "我们当时讨论过什么来着？" | 每条共识都关联到原始对话，随时可查 |

## 快速开始

### 前置条件

确保你已经完成了以下准备：

1. 电脑上安装了 Python 3.12 或更高版本
2. 有 DeepSeek API key（联系管理员获取）
3. IT 同事已经帮你在本地配好了 Vault（密钥管理服务）

### 启动服务

打开终端，先后执行：

```bash
# 第一步：启动后端服务（保持这个窗口开着）
cd apps/qtcloud-connect/src/provider
uv run uvicorn app:app --reload
```

看到 `Application startup complete` 就说明服务启动成功了。

### 打开聊天界面

**再打开一个新终端窗口**，执行：

```bash
cd apps/qtcloud-connect/src/cli
uv run python -m app.main
```

你会看到：

```
qtcloud-connect CLI — 输入消息开始对话，输入 /help 查看命令
==================================================
>>>
```

现在就可以开始聊天了。

## 基础用法

### 发送消息

直接输入你想说的话，按回车：

```
>>> 我们团队决定用 PostgreSQL 作为主数据库
```

AI 会回复你，同时后台的共识智能体会判断这段话有没有值得记录的结论。

### 查看已记录的结论

输入 `/consensuses`，你会看到所有被提炼出来的共识：

```
>>> /consensuses
  [a1b2c3d4] proposed: 团队用 PostgreSQL 作为主数据库
```

每条共识有一个状态：**proposed**（待确认）、**confirmed**（已确认）、**deprecated**（已废弃）。

### 确认结论

确认某条共识，让它成为团队的正式决定：

```
>>> /confirm a1b2c3d4
已确认共识 [a1b2c3d4]
```

### 废弃不再适用的结论

如果之前的决定变了，可以把旧的共识废弃掉：

```
>>> /deprecate a1b2c3d4
已废弃共识 [a1b2c3d4]
```

### 查看所有消息

想看完整的对话记录：

```
>>> /messages
  [msg001] user: 我们团队决定用 PostgreSQL 作为主数据库
  [msg002] agent: 好的，已记录。用 PostgreSQL 作为主数据库。
```

## 共识管理最佳实践

### 想让 AI 记下结论

在说话时带上"记下来"、"总结一下"、"确认这个结论"等关键词，AI 会更主动地提炼共识：

```
>>> 记下来，我们使用 PostgreSQL + Python 技术栈
```

### 闲聊不会被记录

日常闲聊不会被提炼成共识，不用担心污染共识库：

```
>>> 今天天气真不错
```

### 共识的生命周期

```
提出结论 → proposed（待确认）
                ↓
     团队确认 → confirmed（已确认）→ 正式决定
                ↓
     不再适用 → deprecated（已废弃）
```

## 命令速查

| 命令 | 作用 | 示例 |
|------|------|------|
| 直接输入文字 | 发送消息，AI 回复 | `我们选 PostgreSQL` |
| `/consensuses` | 查看所有共识卡片 | `/consensuses` |
| `/confirm <id>` | 确认一条共识 | `/confirm a1b2c3d4` |
| `/deprecate <id>` | 废弃一条共识 | `/deprecate a1b2c3d4` |
| `/messages` | 查看所有消息 | `/messages` |
| `/help` | 显示帮助信息 | `/help` |
| `/quit` 或 `/exit` | 退出 | `/quit` |

## 常见问题

**Q: 我是不是每次都要开两个窗口？**

A: 只需要后台服务启动一次就可以一直用。下次再用的时候，只需要在第一个窗口确认服务还在运行，然后执行第二步的 CLI 命令即可。

**Q: 共识卡片的 ID 好长，每次都要复制粘贴？**

A: 只需要输入前几个字符就够用了。比如 ID 是 `a1b2c3d4e5f6...`，输入 `/confirm a1b2c3d4` 就行——系统会自动匹配。

**Q: 我可以说"不"来否决共识吗？**

A: 可以。AI 会听后续的对话来判断是否需要废弃之前的共识。你也可以手动用 `/deprecate` 来废弃。

**Q: 数据存在哪里？安全吗？**

A: 数据存在你本机的 SQLite 数据库文件 `data/qtcloud-connect.db` 里，不上传任何云端。API key 通过 Vault 管理，不会暴露在代码中。
