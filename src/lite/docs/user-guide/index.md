# 沟通渠道卡片集（lite）

本文说明沟通渠道卡片集的形态、字段与平台口径；要解决的问题见[沟通渠道介绍](../intro/index.md)。

## 管理目标

沟通管理需要记录每个群聊的用途。团队的群聊划分较细，哪个群讲什么、什么内容发到哪里，是沟通渠道管理的重难点，需要把渠道信息统一登记、可查可溯。

## 卡片形态

卡片集把手上的群作为资产逐张列出：一个渠道一张卡，通览一遍即可知道有哪些渠道、各做什么用、出问题找谁。

## 卡片字段

- 名称（label）：渠道或群的名字，卡片的标题。
- 用途描述（description）：渠道的用途，什么内容该往这里放。
- 责任人与成员：群主、管理员与成员，标明谁对渠道负责。
- 关系与分类：渠道间的关系与类别，如正式群与闲聊群的分界，职能群、业务群等。

## 渠道与平台解耦

渠道名带平台前缀，如微信成员群、企业微信成员群、飞书成员群、小红书成员群。各平台对 API 的支持不一致，卡片集先按所有渠道手动管理；待某渠道具备自动化条件，再经适配层接入。卡片本身不与具体平台绑定。
