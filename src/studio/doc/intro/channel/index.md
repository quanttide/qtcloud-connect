# 渠道

渠道决定什么内容发到哪里、出问题找谁。当前量潮的沟通渠道以群聊为载体，群聊的管理口径见[群聊渠道](group.md)。

## 怎么区分渠道

渠道按管理分类分三类：

- 全员群：全员范围，如量潮科技（发通知、同步信息）、闲聊水库（公司闲聊群）。
- 业务群：通知业务类信息，如量潮数据、量潮课堂。
- 职能群：通知职能类信息，如人力资源、财务管理。
