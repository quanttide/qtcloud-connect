# 沟通渠道卡片集（lite）

本文说明沟通渠道卡片集的形态与字段；要解决的问题见[沟通渠道介绍](../intro/index.md)，渠道的查法见[渠道](channel/index.md)。

## 卡片形态

卡片集把手上的群作为资产逐张列出：一个渠道一张卡，通览一遍即可知道有哪些渠道、各做什么用、出问题找谁。

## 卡片字段

- 名称（label）：渠道或群的名字，卡片的标题。
- 用途描述（description）：渠道的用途，什么内容该往这里放。
- 责任人与成员：群主、管理员与成员，标明谁对渠道负责。
- 关系与分类：渠道间的关系与类别，如正式群与闲聊群的分界，职能群、业务群等。
